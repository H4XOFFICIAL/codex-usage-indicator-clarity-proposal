# Codex Usage Indicator Proposal

This proposal adds a choice between a compact usage circle and a visible remaining percentage, plus direct access to an available usage reset from the same menu.

Open `index.html` to explore the prototype. All account, usage, and reset values are examples; the mockup does not connect to an account or redeem a reset.

The [specification](usage-indicator-spec.md) describes the interaction and its safety boundaries. The proposed GitHub issue text is in [github-issue-body.md](github-issue-body.md).

The original screenshots are not included. Project, conversation, and account labels in the mockup are fictional.

Related requests: [#59247](https://github.com/openai/codex/issues/59247), [#25561](https://github.com/openai/codex/issues/25561), and [#48025](https://github.com/openai/codex/issues/48025).
